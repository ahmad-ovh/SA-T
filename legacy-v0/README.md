## 2. Structure of the 5 Mandatory Sections

### Dossier 01: Origin and Interior Context (Thermodynamic Rheology)
- **Thermodynamic Heat Engine:** Planetary accretion, gravitational differentiation (core formation releasing $\sim 2.5 \times 10^{30}\text{ J}$), and decay of radionuclides ($^{26}\text{Al}, ^{238}\text{U}, ^{235}\text{U}, ^{232}\text{Th}, ^{40}\text{K}$) establishing core-mantle heat flux ($\sim 12\text{ TW}$) driving mantle convection.
- **Rheological Regimes:** 
  - *Brittle Lithosphere ($0-100\text{ km}$):* Cold thermal boundary ($T < 1300^\circ\text{C}$); obeys Byerlee's law of friction ($\tau = \mu \sigma_n$); elastic stick-slip seismicity in the upper $0-15\text{ km}$ seismogenic crust.
  - *Ductile Asthenosphere ($100-410\text{ km}$):* High homologous temperature ($T/T_m \approx 0.85-0.95$), low dynamic viscosity ($\eta \approx 10^{19}-10^{21}\text{ Pa}\cdot\text{s}$); deforms plastically via dislocation creep, mechanically decoupling plates.
  - *Brittle-Ductile Transition Zone (BDTZ):* $\sim 350^\circ\text{C}$ isotherm at $\sim 15\text{ km}$ depth.
- **Interactive Element 1:** Real-time Tectonic Cross-Section Physics Simulator with adjustable plate rate, locking depth, asthenospheric viscosity, live telemetry gauges (strain, energy, $M_w$), and stick-slip coseismic rupture trigger with acoustic rumble synthesis.

### Dossier 02: Tectonic Setting & Driving Force Balance
- **Architecture:** Right-lateral (dextral) continental transform fault ($\sim 1,200\text{ km}$) accommodating $\sim 48-50\text{ mm/yr}$ of shear between the Pacific and North American plates. Links the Mendocino Triple Junction to the Gulf of California rift.
- **Physics-Grounded Force Balance:** Demonstrates that while transform faults lack local slabs or ridges, motion is driven by the *far-field torque balance* of the Pacific Plate. **Slab pull** dominates ($\sim 90\%$ of driving torque) from cold, dense lithosphere sinking into Western Pacific subduction zones (Mariana, Kuril, Aleutian trenches), augmented secondarily by ridge push ($\Delta\text{GPE}$) at the East Pacific Rise.

### Dossier 03: The Evidence Layer (4 Independent Empirical Datasets)
1. **GPS Geodetic Velocities & Screw Dislocation Modeling:** Interactive fitting of continuous PBO GPS stations (CARH, VNDN, CAND, CHIL, etc.) using the Savage & Burford (1973) equation:
   $$v(x) = \frac{V_0}{\pi} \arctan\left(\frac{x}{D}\right)$$
   (where $V_0 \approx 36\text{ mm/yr}$, locking depth $D \approx 14\text{ km}$, yielding RMSE $< 0.9\text{ mm/yr}$).
2. **Microseismic Hypocentre Depth Profile:** Relocated USGS NCEDC catalog hypocentres showing abrupt seismicity termination at $15\text{ km}$ (the $350^\circ\text{C}$ BDTZ), contrasting with deep Wadati-Benioff zones.
3. **Marine Magnetic Striping Isochrons:** Pacific seafloor magnetic anomaly lineations (Chrons 1–21; Atwater, 1970) proving seafloor spreading history and dating the ridge-trench collision at $\sim 30\text{ Ma}$.
4. **Geomorphic Offset Caliper (Wallace Creek):** Interactive digital caliper measuring the $130\text{ m}$ right-lateral stream offset in the Carrizo Plain dated to $3,700\text{ yr BP}$ via $^{14}\text{C}$, deriving Holocene slip rate of $35.1\text{ mm/yr}$ (Sieh & Jahns, 1984).

### Dossier 04: Then and Now (200 Million Year Evolution)
- **Interactive Element 2:** Video-playback style paleogeographic timeline player with Play, Pause, Rewind, Fast-Forward, and scrubbing slider across 5 geological epochs:
  - **200 Ma (Early Jurassic):** Farallon subduction under North America, Pangea breakup.
  - **100 Ma (Late Cretaceous):** Andean-style subduction and Sierra Nevada magmatic arc.
  - **30 Ma (Oligocene):** Spreading ridge collides with continental trench; subduction terminates; slab window opens; Mendocino & Rivera triple junctions launch the proto-San Andreas transform fault.
  - **0 Ma (Present):** Modern $1,200\text{ km}$ continental transform fault.
  - **+30 Ma (Future):** Continued dextral translation juxtaposes Los Angeles with San Francisco and transports Baja terranes toward Alaska.

### Dossier 05: Why It Matters & Explicit Malaysia Nexus
- **California Hazards & Basin Resources:** Locked Southern SAF ($>330\text{ yr}$ slip deficit, $M_w 7.8+$ ShakeOut hazard); lifeline slip joints; LA pull-apart oil basins; Salton Sea geothermal lithium extraction.
- **Explicit Connection to Malaysia:**
  1. *Sumatran Strike-Slip Analogue:* The $1,900\text{ km}$ dextral Great Sumatran Fault shares identical kinematics with the SAF, radiating long-period shear waves into Peninsular Malaysia.
  2. *Reactivated Basement Faults:* Ancient shear zones (e.g., Bukit Tinggi Fault Zone) reactivated under Sunda plate compressive stress ($M_w 1.5-3.5$ swarms; Shuib, 2009).
  3. *Sabah Active Faulting:* The 2015 $M_w 6.0$ Ranau earthquake on Mount Kinabalu (Mensaban fault; Tongkul, 2016).
  4. *Structural Building Codes:* Malaysia National Annex to Eurocode 8 (MS EN 1998-1:2015).
- **Interactive Element 3:** Malaysia Structural Resonance Simulator demonstrating how soft Klang Valley marine clays amplify distant long-period shear waves, causing resonance in high-rise towers.

## 4. How to Deploy to GitHub Pages
The web application is built with 100% vanilla HTML5, CSS3, and JavaScript with zero external runtime dependencies. It runs completely offline and is pre-configured for GitHub Pages:

1. Create a new GitHub repository (e.g., `sktp2613-san-andreas-fault`).
2. Upload the local files (`index.html`, `styles.css`, `app.js`, `README.md`) to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: SKTP2613 Tectonic Story Artefact"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/sktp2613-san-andreas-fault.git
   git push -u origin main
   ```
3. In your GitHub repository, navigate to **Settings** > **Pages**.
4. Under **Build and deployment** > **Branch**, select `main` and folder `/ (root)`, then click **Save**.
5. Within 1–2 minutes, your website will be live at:
   `https://YOUR_USERNAME.github.io/sktp2613-san-andreas-fault/`
6. Test the link in an incognito/private browser window before submitting your PDF cover sheet on e-Learning!
